## 📖 چشم‌انداز
هدف فیلم‌نویس این است که یک جایگزین بومی، رایگان و متن‌باز برای استانداردهای صنعتی مانند Final Draft باشد که به طور خاص برای زبان فارسی و تایپوگرافی راست‌چین (RTL) طراحی شده است. تمرکز این پروژه بر تجربه نوشتن بدون حواس‌پرتی، فرمت‌بندی استاندارد فیلمنامه (صحنه، اکشن، شخصیت، دیالوگ و غیره) و صفحه‌بندی واقعی است.

## 🔬 تکامل پروژه و آرشیو تحقیق و توسعه
ساخت یک ویرایشگر فیلمنامه غنی (Rich-Text) یک چالش مهندسی پیچیده است. قبل از رسیدن به معماری فعلی، این پروژه مراحل گسترده‌ای از تحقیق و توسعه (R&D) را طی کرده است.

پوشه [`/archive`](./archive) در این مخزن شامل دو نمونه اولیه است. اگرچه آن‌ها برای استفاده نهایی آماده نبودند و در نهایت رها شدند، اما آن‌ها به عنوان مطالعات موردی ارزشمندی در مورد محدودیت‌های فریم‌ورک‌های رابط کاربری برای فرمت‌بندی بلوکی متن غنی عمل می‌کنند:

۱. **نمونه اولیه GTK4:** تلاشی برای استفاده از `Gtk.TextBuffer`. این نسخه به دلیل مشکلات شدید عملکردی و محدودیت‌های ذاتی در مدیریت حاشیه‌های پیچیده بلوک‌ها (تفاوت دیالوگ و اکشن) بدون تکیه بر راه‌حل‌های موقت، رها شد.
۲. **نمونه اولیه Qt:** یک جهش معماری بزرگ به جلو با استفاده از PySide6 و `QTextDocument`. این نسخه ثابت کرد که Qt ابزار مناسب برای این کار است. با این حال، آرشیو شد زیرا پیاده‌سازی *صفحه‌بندی واقعی* و بهینه‌سازی عملکرد برای فیلمنامه‌های طولانی، برای آن طراحی خاص کدبیس بسیار پیچیده بود.

*شما می‌توانید گزارش فنی کامل (Post-mortem) این نمونه‌های اولیه را در فایل [`archive/README.md`](./archive/README.md) بخوانید.*

## ✨ قابلیت‌ها (برنامه‌ریزی شده برای نسخه نهایی)
- [x] **بومی RTL:** پشتیبانی درجه یک از جهت متن و تایپوگرافی فارسی.
- [x] **فرمت‌بندی استاندارد:** مدیریت هوشمند المان‌های استاندارد (عنوان صحنه، اکشن، شخصیت، پرانتز، دیالوگ، انتقال).
- [x] **میانبرهای هوشمند:** کلیدهای `Ctrl+1..6` برای تغییر سریع المان‌ها و جریان هوشمند کلید `Enter`.
- [x] **صفحه‌بندی سفارشی A4:** شکستن صفحات واقعی که شبیه صفحات فیزیکی واقعی است.
- [ ] **گزینه‌های خروجی:** خروجی PDF و فرمت‌های استاندارد (به زودی).
